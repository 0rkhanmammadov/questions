# Quiz Assistant (Windows Desktop)

Windows üzərində ekran kəsimi (OCR/Vision) və mətn seçimi vasitəsilə test suallarını həll edən masaüstü köməkçi.

## Quraşdırma və İşə Salma (CMD)

```cmd
git clone <SƏNİN_GİT_REPO_LİNKİN> quiz-helper
cd quiz-helper
qurasdir_ve_baslat.bat
```

Artıq paketlər quraşdırılıbsa, birbaşa işə salmaq üçün:
```cmd
baslat.bat
```

## Qısa Yollar
- `Ctrl + X` (və ya `PrintScreen`) — Tam ekran skrinşotundan sualı oxuyub həll et
- `Ctrl + Maus Sol Çəkmə` — Seçilən ekran sahəsinin skrinşotundan sualı həll et
- `Ctrl + C` — Seçilmiş mətni həll et (kopyalama bağlıdırsa avto-skrinşot çəkir)
- `Ctrl + Shift` (basılı saxla) — Cavabı və statusu göstər
- `Ctrl + Shift + S` — Ayarlar pəncərəsi
- `Ctrl + Shift + Q` — Tam çıxış
